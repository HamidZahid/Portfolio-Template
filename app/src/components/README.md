# Components Directory

This directory contains all React components organized by their purpose.

## Structure

### `/ui`
Reusable UI components that can be used across the application:
- **`buttons/`** - Button components (PrimaryButton, SecondaryButton, IconButton, etc.)
- **`cards/`** - Card components (ProjectCard, BlogCard, etc.)
- **`forms/`** - Form components (Input, Textarea, Select, etc.)
- **`modals/`** - Modal and dialog components

### `/layout`
Layout components that structure the page:
- **`header/`** - Header component
- **`footer/`** - Footer component
- **`navigation/`** - Navigation menu components

### `/sections`
Page sections for the portfolio:
- **`hero/`** - Hero/landing section
- **`about/`** - About section
- **`projects/`** - Projects showcase section
- **`skills/`** - Skills section
- **`contact/`** - Contact form section

## Component Naming Convention
- Use PascalCase for component files: `Button.tsx`
- Export components as default or named exports
- Include TypeScript types for props
